# Three-minute demonstration

0:00–0:25 — Open Verify. Say: “ModelLedger is a digital passport for AI images. It verifies evidence rather than guessing a model from the pixels.” Point to the privacy controls and four possible outcomes.

0:25–0:55 — Select the final Platform D demo sample. The result should be VERIFIED under the development policy. Explicitly call out the SIMULATED banner: the providers are procedural fixtures, while event signatures, EVM anchors and independent witness records are real.

0:55–1:20 — Open Provenance graph. Show Model A generation, Model B upscaling, Tool C's ordered crop-plus-blur export and Platform D's JPEG reencoding. Click a node to reveal the version fingerprint and event hash. Explain that one export is one version, regardless of the number of editing actions.

1:20–1:40 — Verify the unregistered heavy-blur sample. The result is UNVERIFIABLE, potentially with a similar known candidate. Explain that a visual match cannot inherit another image's signatures. Extreme blur or crop can destroy recoverable evidence entirely.

1:40–2:00 — Open the signed certificate for the verified report. Download JSON or PDF. It certifies this verification result, not originality. Explain that owner-side prompt commitments can support a selective disclosure without publishing every private field.

2:00–3:00 — Open Adversarial lab and run all scenarios. Show the authorized-signer-lies case, impersonation, parent mutation, retroactive revocation, Sybil witness and privacy proof checks. Finish with the actual passing scenario count. If a scenario fails, inspect it rather than claiming it passed.
